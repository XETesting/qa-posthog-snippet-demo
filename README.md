# qa-posthog-snippet-demo

Minimal static page with the PostHog JS snippet for **qa-posthog** (project `633060`) connector QA.

## Use

1. Open the GitHub Pages URL for this repo (or serve `index.html` locally).
2. Click around / use the buttons to send demo events.
3. Confirm events in PostHog → Activity / Insights for project `qa-posthog`.

## Notes

- Project API key in the snippet is the public frontend token (expected in client-side HTML).
- Disposable naming: events use `qa_seed: path-c-web`.
